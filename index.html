ブロックをつなぐだけで、Python が書ける。

faq

よくある質問

PycoBlocks は無料で使えますか？

はい、完全に無料です。アカウント登録もインストールも不要で、ブラウザを開くだけですぐに使えます。ソースコードは MIT ライセンスで公開しています。

インストールは必要ですか？

必要ありません。PycoBlocks はブラウザだけで動作します。Python の環境構築やアプリのインストールは不要で、開いた瞬間からブロックを組んで実行できます。

Scratch との違いは何ですか？

PycoBlocks はブロックを組むと本物の Python / MicroPython コードが常に隣に表示されます。ブロックとコードを見比べながら学べるため、Scratch の次にテキストプログラミングへ進む一歩として最適です。

実機（マイコン）がなくても使えますか？

使えます。Python 入門モードとゲームモードはブラウザ内でそのまま実行できるため、実機は不要です。Raspberry Pi Pico などのマイコンが必要なのは MicroPython モードだけです。

対応ブラウザは？

Python 実行とゲームは Chrome・Edge・Safari・Firefox で動作します。Raspberry Pi Pico への接続・書き込みには Web Serial API が必要なため、Chrome または Edge のデスクトップ版が必要です。

何歳から使えますか？

ブロック操作なので小学校中学年ごろから使えます。ループ・リスト・辞書・関数・クラスまでカバーしているので、中学生・高校生・高専生の本格的な Python 学習にも対応します。

学校の授業で使えますか？

はい。インストール・アカウント登録が不要で、スマホやタブレットにも対応しているため、1人1台端末の授業でそのまま使えます。MIT ライセンスなので教育利用も自由です。
