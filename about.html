PycoBlocksとは

ブロックを組むだけで Python / MicroPython を自動生成し、ブラウザ上でそのまま実行できる無料の学習環境です。Raspberry Pi Pico・micro:bit に対応しています。

▶ PycoBlocks を開く（無料・登録不要）

PycoBlocks（ピコブロックス）は、プログラミングがはじめての小中学生から、Python やマイコン制御を学ぶ高校生・高専生までを対象にした、ブラウザだけで動くブロックプログラミング環境です。インストールやアカウント登録は不要で、開いた瞬間から使えます。大阪公立大学高専の教員が運営する 魁高専（SAKIGAKE Robotics） の教育プロジェクトとして無料公開しています。

PycoBlocks の特長

ブロック → 本物のコード

ブロックを組むと、対応する Python / MicroPython のコードが自動で生成されます。ブロックとコードを見比べながら、テキストプログラミングへ自然に進めます。

ブラウザですぐ実行

書いたプログラムはブラウザ上でそのまま実行できます。環境構築でつまずくことなく、結果をすぐに確かめられます。

実機に書き込める

Raspberry Pi Pico / Pico W や micro:bit へシリアル接続し、作ったプログラムを実機へ書き込んで動かせます。

ゲームも作れる

ゲーム制作モードを使えば、ブロックでオリジナルのゲームづくりに挑戦できます。楽しみながらプログラミングの考え方が身につきます。

使い方は3ステップ

  1. ブラウザで開く — PycoBlocks のページを開きます。インストールは不要です。
  2. ブロックを組む — 用意されたブロックをドラッグして並べると、右側に Python / MicroPython のコードが自動生成されます。
  3. 実行する／書き込む — ブラウザで実行して動きを確認。Raspberry Pi Pico や micro:bit をつないで実機に書き込むこともできます。

対応している機器・言語

  • マイコン：Raspberry Pi Pico / Raspberry Pi Pico W / micro:bit
  • 生成される言語：Python（標準）／ MicroPython（マイコン向け）
  • 動作環境：パソコン・タブレットのブラウザ（実機書き込みは Chrome / Edge など Web Serial 対応ブラウザ）

よくある質問（FAQ）

PycoBlocks は無料で使えますか？
はい、無料です。アカウント登録もインストールも不要で、ブラウザを開くだけですぐに使えます。
どんなプログラミング言語を学べますか？
ブロックを組むと Python と MicroPython のコードが自動で生成されます。ブロックとコードを見比べながら、本物のテキストプログラミングへ無理なく進めます。
どんな機器に対応していますか？
Raspberry Pi Pico / Pico W や micro:bit などのマイコンに対応しています。ブラウザからシリアル接続して、作ったプログラムを実機へ書き込めます。
対象年齢・レベルは？
小中学生のプログラミング入門から、高校・高専での Python 学習やマイコン制御まで対応しています。ゲーム制作モードもあり、楽しみながら学べます。
インストールは必要ですか？
必要ありません。PycoBlocks はブラウザだけで動作します。実機への書き込みには Chrome / Edge など Web Serial 対応ブラウザを使います。
